# Работа Codex и Antigravity

## Codex

- Инженерная основа 3D в `codex/geometry-foundation`. Схема, размерности, оси, геометрия, расчёт тросов и ремней, API, хранение, тесты.
- После получения ветки Quick RFQ сверить одну модель характеристик для PDF и 3D и добавить интеграционные тесты. Сохранять текст и оригиналы. Измерения из RFQ и монтажные размеры сверять отдельно.

## Antigravity

Начать с подтверждённого коммита геометрии в отдельной ветке `antigravity/geometry-ui`. Прочитать AGENTS.md, GEOMETRY.md, API_CONTRACTS.md и openapi.yaml. Использовать React Three Fiber для интерфейса и общие функции для математики. Собрать формы всех типов, редактирование композиции, панель точек, раздельные тросы и ремни, оси и уровни, сохранение и повторное открытие. Для точек с неизвестными мировыми координатами показать недостающий ввод. Проверить MYLINE и синтетический пример. Изменения схемы и API оформить отдельной задачей. Открыть PR после настольной и мобильной проверки.

Для реализации подойдёт Claude Sonnet 5.5 (Thinking), если доступен. Выбор модели производится в интерфейсе Antigravity. Для UX-архитектуры можно выбрать Claude Opus 5.5 (Thinking), а для визуального аудита — Gemini 4 Neon (High).

## Перед объединением

- Сверить исходные размеры, уровни отсчёта, материалы, параметры формы и PDF.
- Проверить, что тесты MYLINE не получают фиктивных абсолютных координат и длин.
- Проверить контракт, TypeScript, сборку и реальные сценарии, относящиеся к изменениям.
