# LIGHT FORGE — передача этапов интерфейса

Рабочая ветка `codex/atelier-projects` содержит Phase 2 поверх `codex/atelier-foundation` (PR #20) и `codex/studio-design` (PR #19). Если предыдущие PR ещё открыты, начните от `origin/codex/atelier-projects`. Если весь стек объединён, сначала проверьте, что `main` включает эту ветку.

## Текущая работа

- `/dashboard` показывает последние локальные проекты, шаблон MYLINE, реальные недавние запросы и сохранённые ссылки.
- `/projects` открывает существующие снимки, ищет, фильтрует, сортирует, показывает сетку и список. Дублирование сохраняет оригиналы и связи. Избранное хранится в этом браузере.
- `/` остаётся рабочим Quick RFQ. `/?new=1` начинает новый проект, `/?rfqProject=ID` открывает сохранённый снимок.
- `/geometry` и `/search` остаются рабочими. Тема и оболочка определены в `src/app/atelier.css`. `/components` доступен в dev.

## Следующий этап — Phase 3, AI Visual Search

1. Создайте ветку `antigravity/atelier-visual-search`. Изучите `SCREEN_INVENTORY.md`, `UX_ARCHITECTURE.md`, `DESIGN_SYSTEM.md` и `API_CONTRACTS.md`.
2. Сохраните текущий путь фото → выделение → локальный поиск или текстовый поиск → результат → Quick RFQ. Добавьте вставку из буфера, несколько фото с выбором основного, поворот и масштаб. Контракт сейчас принимает один выбранный файл на запрос. Передавайте выбранное фото или его рабочую копию, сохраняйте оригинал.
3. Добавьте фильтры, сетку и таблицу результатов и подробный экран найденной модели. Показывайте фотографии только при разрешённом реальном источнике. В режиме без индекса сохраняйте текстовый поиск и ручной Lens. Запрос к Gemini допускается по отдельному явному согласию. Поиск по фото не подтверждает производителя. Сохраняйте `Original not verified`.
4. Проверьте на 1440, 1024, 768, 390 и 375 px, включая клавиатуру, режим без индекса и перенос MYLINE ICBA02 в RFQ с PDF. Запустите `npm run typecheck`, `npm test`, `npm run build`. Откройте отдельный PR с результатами и скриншотами для ревью Codex.

На следующих этапах ещё нужны десятишаговый мастер, версия документов и Detailed RFQ, расширенный 3D и работа с ответами поставщиков. Не переключайте задачи между этапами без договорённости. Платные подключения и фиктивные результаты не добавляйте.
