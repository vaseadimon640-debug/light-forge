# Architectural Atelier

Светлая тема использует молочный фон, графитовый текст и латунь для выбранного раздела и ключевых действий. Тёмная тема хранится в этом браузере. Лист RFQ остаётся светлым, чтобы соответствовать печатному документу. Общие токены описаны в `src/app/atelier.css`, стили существующих рабочих элементов — в `globals.css` и модулях страниц.

| Роль | Применение |
| --- | --- |
| Display | Короткие заголовки рабочих разделов и вводные блоки, Georgia |
| Page / Section / Card | Иерархия заголовков с одним h1 на экран, системный sans-serif |
| Body / Caption | Рабочий текст и пояснения, нормальный регистр |
| Technical / Value | Единицы рядом со значением, табличные цифры, отдельная метка происхождения |

Базовые кнопки, поля, сегменты и уведомления используют общие стили. Выбранное состояние выражается через ARIA и цвет, ошибки имеют видимую подпись, фокус очерчивается контрастной линией. Нативный dialog используется для мобильной навигации, details для небольших раскрывающихся блоков. Переходы короткие и отключаются при prefers-reduced-motion.

Внутренний маршрут `/components` доступен в dev. Он показывает кнопки, поля, список подсказок, сегменты, чекбоксы, ползунок, выпадающий список, раскрытие, прогресс, ошибки и пустое состояние. Специализированные элементы уже есть в RFQ, Search и 3D. Их унификация и общие варианты загрузки, пустого состояния и ошибок выполняются вместе с соответствующими сценариями.
